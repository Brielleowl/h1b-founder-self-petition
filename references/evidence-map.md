# Evidence: what to collect, where it uploads, how the exhibit index reads

## Documents to collect

**Company (petitioner)**
| Document | Why | Typical source |
|---|---|---|
| Certificate of Incorporation / Articles of Organization | legal existence | Delaware Division of Corporations, Stripe Atlas, Clerky |
| Foreign-qualification in the worksite state (e.g. California Statement and Designation by Foreign Corporation + Certificate of Qualification) | company may lawfully operate where the worksite is | Secretary of State |
| IRS EIN confirmation (CP 575 or 147C) | EIN on the I-129 | IRS |
| Bylaws, Action of Incorporator, board / stockholder consents naming directors and officers | who signs; founder's titles | formation package |
| Stock certificate / cap table / stock ledger | controlling interest % | formation package, Carta |
| Business bank account statement or balance page | ability to pay | bank |
| Lease or proof of worksite (a home lease is fine if it allows at-home business use) | worksite exists | landlord |
| Business plan | the position is real and the company can pay | you draft it (`templates/business-plan-outline.md`) |
| Website screenshots, pitch deck | corroboration | you produce (PDF) |

**Beneficiary**
| Document | Why |
|---|---|
| Passport bio page; most recent visa | identity |
| Every I-797 approval notice (each has the I-94 number and expiry) | status history, cap-count proof, A-Number |
| CBP I-94 record (i94.cbp.dhs.gov) | last arrival |
| Last 2–3 pay stubs or W-2 from the prior H-1B employer | maintenance of status |
| Diplomas and official transcripts; credential evaluation for a foreign degree | qualification |
| Résumé | optional |

**Position**
| Document | Why |
|---|---|
| **Certified LCA (ETA-9035), signed by the employer** | required |
| Job description | specialty occupation; also the LCA's public-access-file wage memo refers to it |
| Offer letter signed by both sides (employment agreement optional) | bona fide offer, written terms |
| Sole-director / board consent creating the position and authorising the petition | corporate authority, disclosure of interest |
| Support letter | the argument |
| OOH entry for the SOC code (print to PDF) | degree is normally required |
| 3–6 job postings for parallel positions at similar companies (optional) | industry standard |
| Expert opinion letter (optional) | duties require the degree |

Do **not** collect or submit: the beneficiary's personal bank statements, a founder "funding
commitment" letter, a former employer's reference letter unless the user wants it, anything naming a
former employer's customers or contracts.

## Upload categories on the online I-129

Category names shift; match by meaning.

| Document | Category |
|---|---|
| Certified LCA | Labor Condition Application |
| Signed offer letter (+ employment agreement) | Written contract or terms of agreement |
| Board / sole-director consent | Evidence of available position |
| Job description | Evidence of qualified specialty occupation |
| Support letter | Petitioner's statement / support letter (or "Other" if no such category) |
| Diplomas, transcripts, evaluation | Beneficiary's degree / education |
| Passport, visa, I-94, all I-797A notices, pay stubs | Beneficiary's current status / maintenance of status |
| Incorporation certificate, state qualification, EIN letter, bylaws, consents, stock ledger | Petitioner's business documents / organisational documents |
| Business plan, bank balance page, website screenshots, pitch deck, lease clause | Other supporting evidence (or "Evidence of ability to pay" if offered) |
| OOH page, job postings, expert letter | Evidence of specialty occupation / Other |

One PDF per document, under 6 MB each is safe. Filenames: `Company-Document-Name.pdf`, no commas.

## Exhibit index (as used in the support letter)

| Exhibit | Document |
|---|---|
| A | Certificate of Incorporation |
| B | Bylaws; Action of Incorporator; director/stockholder consents (including the consent creating the position) |
| C | Stock certificate and stock ledger |
| D | IRS EIN confirmation; state foreign-qualification documents |
| E | Business Plan |
| F | Job Description |
| G | DOL Occupational Outlook Handbook entry for the occupation |
| H | Job announcements for parallel positions (optional) |
| I | Expert opinion letter (optional) |
| J | Beneficiary's diploma(s) and transcript(s) |
| K | Verification of prior employment (pay stubs / W-2; reference letter optional) |
| L | Certified LCA, signed |
| M | Offer of employment (and employment agreement if any) |
| N | Company bank statement / balance page |
| O | Prior H-1B approval notices, I-94, recent pay statements |
| P | Website screenshots, pitch deck, lease clause (optional) |

Drop optional exhibits the user decides not to submit and re-letter the rest; the support letter must
not cite an exhibit that is not uploaded.
